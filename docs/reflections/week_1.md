# Reflections for Week 1 (June 8 - 12)

- First log for summer AI engineering research pilot.
- On our first session it was mentioned to not use Pi agent on hex. I made a clone of my pyEPM repo locally on the computer to use the agent on.
- First task: develop a personal website for our research projects.
- Wrote an AGENTS.md file for the agents context window, and provided my personal and research information through md files.
- I then gave instructions to the agent to develop my website. I wanted different clickable tabs for each section of the webpage, and teh agent decided Next.js would be the best development framework for the task.
- Used GPT 5.5 for the initial planning. First pass looked good, but there was a lot of redundant information. For example the first "Home" tab had basically the same content as all the other tabs. This probably makes sense as I didn't provide that much content and I didn't specify what I wanted in the Home page.
- Tweaked and modified the webpage to my liking. I used GPT 5.4 for this, these tasks are much lighter.
- Something I noticed was that the window would annoyingly shift a little between the Home and the other tabs. Working with the agent we found out that the Home tab didn't have a scroll bar, and this was causing the small shift between windows.
- For the Project tab I added some result plots from my work. I made a "scrolley" telling panel for these.
- Last I implemented a timeline panel on the About me page. I added some little easter eggs for my pets.
