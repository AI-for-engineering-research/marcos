# Marcos Logroño Research Portfolio

A professional academic portfolio built with Next.js to present ongoing engineering research, document AI-assisted development work, and maintain a lightweight, readable web presence.

## Goals
- Present a professional academic portfolio website
- Showcase an AI-assisted engineering research project
- Document the use of AI agents on a weekly basis
- Keep pages lightweight, readable, interactive, and creative

## Current sections
- Home
- Research
- About
- Updates

## Tech stack
- Next.js
- React
- TypeScript
- Tailwind CSS

## Project structure
- `src/app/` — app routes
- `src/components/` — shared UI components
- `src/lib/` — site content and shared data
- `public/` — web assets
- `docs/` — feature documentation
- `about_me.md` and `research.md` — preserved source content from the original repository state

## Getting started
Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
